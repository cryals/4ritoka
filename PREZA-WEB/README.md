# Fabriq — web-презентация

Автономная презентация курсового проекта. Зависимости и сборка не требуются.

В составе — девять слайдов с навигацией с клавиатуры, touch-переключением и адаптивной компоновкой.

Готовая речь на 15 минут, тайминг и ответы на вопросы находятся в [DOKLAD.md](DOKLAD.md).

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```powershell
cd PREZA-WEB
python -m http.server 8080
```

После этого откройте `http://127.0.0.1:8080`.

## Управление

- `←` / `PageUp` — предыдущий слайд;
- `→` / `PageDown` / `Space` — следующий слайд;
- `Home` / `End` — первый или последний слайд;
- `H` — скрыть или вернуть кнопки;
- `F` — полноэкранный режим;
- свайп — переключение на touch-устройствах.

Текущий слайд сохраняется в URL как `#slide-N`, поэтому на него можно дать прямую ссылку.
