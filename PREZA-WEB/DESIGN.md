# Fabriq presentation website — design specification

## Purpose

Автономная HTML-презентация для защиты курсового проекта Fabriq. Автор: Горбатков Никита Романович, группа П313. Вуз, кафедра и руководитель не указываются.

## Delivery

Все файлы находятся в `PREZA-WEB/`. Сайт запускается открытием `index.html`, не требует сборки, сервера или внешних зависимостей.

## Slide structure

1. Титульный слайд: Fabriq, тема проекта, автор и группа.
2. Проблема: сложность оценки производственной линии до изменений в цехе.
3. Цель и задачи: моделирование, сценарии, аналитика, сравнение результатов.
4. Решение: возможности web-приложения Fabriq.
5. Архитектура и тестовый контур: Browser → Next.js/SQLite → FastAPI → Python engine; результаты предварительного параллельного теста.
6. Путь пользователя: сценарий → параметры → очередь → расчёт → анализ → сравнение.
7. Интерфейс и демонстрация: основные пользовательские экраны и данные результата.
8. Результаты и развитие: завершённые функции, измеренная производительность, границы оценки и направления масштабирования.

## Performance story

- Не использовать формулировку «20 пользователей»: тест проверяет параллельные расчётные запросы, а не размер аудитории.
- Проверенные показатели: 20 из 20 параллельных запросов завершились с HTTP 200; wall time теста — 0,88 секунды.
- Производная оценка тестового контура: около 23 расчётов в секунду для базового сценария (`20 / 0,88`). Это предварительный локальный ориентир, а не production SLA.
- Масштабирование показывается как независимое расширение web-контура, очереди и Python workers. Утверждение о 1000 одновременных пользователях без отдельного end-to-end теста не используется.
- Инфографика должна визуально разделять «проверено сейчас» и «следующий уровень», чтобы прогноз выглядел оптимистично, но оставался защищаемым.

## Visual direction

- Формат 16:9, каждый слайд занимает весь viewport.
- Палитра сайта: `#0b0c0e`, `#f7f7f5`, `#ffffff`, `#656970`, `#cfd1d3`, `#ffcc00`.
- Display: Bahnschrift/Arial Narrow; body: Inter/Arial; utility: Cascadia Code/Consolas.
- Без карточной сетки: композиция строится крупной типографикой, разделительными линиями, индексами и одним жёлтым акцентом.
- Уникальный элемент — тонкая «производственная линия», которая меняет форму и назначение от слайда к слайду.
- На технических слайдах линия превращается в шкалу нагрузки, throughput-график и контур горизонтального масштабирования.
- Анимации короткие и функциональные; `prefers-reduced-motion` отключает их.

## Controls

- В левом нижнем углу: назад, вперёд, скрыть панель.
- `ArrowLeft`, `ArrowRight`, `Space`, `PageUp`, `PageDown`, `Home`, `End`.
- `H` скрывает и возвращает панель; `F` включает fullscreen.
- Свайпы влево/вправо на touch-устройствах.
- Номер текущего слайда и прогресс остаются частью композиции.
- Состояние текущего слайда отражается в URL hash, поэтому слайд можно открыть прямой ссылкой.

## Responsive and accessibility

- Масштабирование от ноутбука до проектора и мобильного экрана.
- Semantic sections, явные `aria-label`, видимый `:focus-visible`.
- Контрастные кнопки размером не менее 44×44 px.
- При отключённом JavaScript первый слайд и краткое сообщение остаются читаемыми.

## Files

- `index.html` — разметка восьми слайдов и controls.
- `styles.css` — visual system, layouts, motion и responsive rules.
- `script.js` — navigation state, keyboard, touch, fullscreen и URL hash.
- `README.md` — запуск и горячие клавиши.

## Acceptance criteria

- Ровно 8 содержательных слайдов без фиктивных данных.
- Все элементы помещаются в 16:9 без вертикальной прокрутки.
- Назад/вперёд работают мышью, клавиатурой и свайпом.
- Панель полностью скрывается и возвращается клавишей `H`.
- Hover применяется только к интерактивным элементам.
- Презентация открывается локально без установки зависимостей.
