# Презентация Fabriq

В репозитории находится автономная HTML-презентация курсового проекта и готовая речь продолжительностью около 15 минут.

## Файлы

- `PREZA-WEB/index.html` — девять интерактивных слайдов;
- `PREZA-WEB/DOKLAD.md` — основной текст выступления, тайминг и ответы на вопросы;
- `PREZA-WEB/styles.css` — оформление и адаптивная раскладка;
- `PREZA-WEB/script.js` — управление слайдами.

## Запуск всего проекта

На Windows используйте корневой launcher:

```powershell
.\START-FABRIQ.bat
```

После подготовки зависимостей и production-сборки он запускает:

- Fabriq Web: `http://127.0.0.1:3000`;
- Python API: `http://127.0.0.1:8000`;
- Swagger: `http://127.0.0.1:8000/docs`;
- документацию: `http://127.0.0.1:3001/Fabriq/`;
- презентацию: `http://127.0.0.1:8080`.

Состояние процессов и журналы доступны командами:

```powershell
.\START-FABRIQ.bat status
.\START-FABRIQ.bat logs
.\START-FABRIQ.bat stop
```

## Управление презентацией

- `←`, `PageUp` — предыдущий слайд;
- `→`, `PageDown`, `Space` — следующий слайд;
- `Home`, `End` — первый или последний слайд;
- `H` — скрыть или вернуть кнопки;
- `F` — полноэкранный режим.

Каждый слайд имеет адрес вида `http://127.0.0.1:8080/#slide-N`.
