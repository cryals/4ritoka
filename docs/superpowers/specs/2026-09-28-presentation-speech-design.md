# Fabriq presentation speech design

## Goal

Подготовить готовую к чтению речь продолжительностью около 15 минут для восьмислайдовой HTML-презентации Fabriq.

## Canonical file

Основной файл находится рядом с презентацией: `PREZA-WEB/DOKLAD.md`.

## Structure

- Краткая памятка перед выступлением и ориентир по времени.
- Восемь разделов по порядку слайдов.
- Для каждого слайда: рекомендуемый тайминг, момент переключения и связный текст выступления.
- Технические решения объясняются через задачу, альтернативы и причины выбора.
- Нагрузочные показатели отделяют факты теста от предварительной оценки.
- После основной речи: короткое завершение и ответы на вероятные вопросы комиссии.

## Content requirements

Доклад объясняет:

- производственную проблему и пользу дискретно-событийного моделирования;
- модель сценария, события, очереди, станки, отказы и воспроизводимость через seed;
- разделение Browser, Next.js, SQLite, FastAPI и Python engine;
- выбор SQLite WAL вместо PostgreSQL, встроенной очереди вместо Redis и FastAPI как тонкого адаптера;
- пользовательский путь от выбора сценария до сравнения запусков;
- хранение истории, авторизацию, изоляцию пользователей, экспорт и резервные копии;
- тестовые показатели `20/20`, `0,88 с`, `≈23 расчёта/с` и `73` автоматических теста;
- границы этих показателей и путь масштабирования;
- практическое влияние на инженера, технолога и руководителя производства.

## Documentation updates

- Корневой `README.md` получает раздел о презентации и ссылку на речь.
- `PREZA-WEB/README.md` получает ссылку на файл выступления.
- В Docusaurus добавляется страница `docs/docs/presentation.md` и пункт sidebar.
- Устаревшая формулировка о «20 пользователях» заменяется точным описанием проверенной конкурентной нагрузки.

## Validation

- Текст читается примерно за 15 минут при темпе 120–135 слов в минуту.
- Все цифры совпадают с тестами и презентацией.
- Markdown не содержит незаполненных секций.
- Docusaurus проходит production build.
- API, web-приложение, документация и презентация доступны по локальным URL.
